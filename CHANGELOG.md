# Changelog

All notable changes to this project are documented here. Format loosely follows
[Keep a Changelog](https://keepachangelog.com/), and versions follow
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-09-24

Initial public release.

### Added
- Core healing gameplay loop: your party fights and takes damage automatically, you keep them
  alive with a mana-based healing spell kit.
- 5-slot action bar loadout, configurable between fights (choice of spells, bar position, hotkeys).
- 3 boss encounters, each playable on Normal and Heroic difficulty.
- 5 healing spells: Greater Heal, Renew, Circle of Healing, Power Word: Shield, Shadow Word: Death.
- Save/load with multiple save slots.
- WebGL build published on itch.io.
